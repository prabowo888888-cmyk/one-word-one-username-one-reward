## The entry: prabowo-2

The bounty asks each entrant to send their own make.fun username as one
word, with no explanation, no links and no pitch. This entry sends
**prabowo-2**, the entrant's own handle.

A handle is judged on whether it makes the reader smile on first sight
and sticks in the mind after one look. "prabowo-2" is short and plain:
a name plus a small number, the kind of tag that looks like it belongs
to a real person rather than a slogan. It is easy to say, easy to
remember, and it carries no jab at anyone — it is simply the name its
owner wears. That is the whole case for it: nothing dressed up, nothing
tacked on, just the username standing on its own.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` — exactly 10 bytes, `prabowo-2`, with no
trailing newline. The program checks its own output before finishing:
the file must be exactly the username's bytes, or it exits with an
error. Running it twice produces byte-identical output every time.
